# Data Sources, Provenance & Methodology Statement

This project analyzes social media engagement and audience comment interactions for Pakistani fashion retail brands, specifically focusing on **women's lawn suits and pret collections** during peak shopping seasons (11.11, 12.12, and Eid-ul-Fitr).

## 2. Reference & Benchmark External Data Sources

In accordance with academic research standards and course specifications, this project references the following real-world Pakistani data repositories:

### A. Pakistani Fashion Brand Social Media Sentiment Research
- **Paper:** *Sentiment Analysis of Social Media Data for Pakistani Fashion Brand Monitoring Using Machine Learning* (2026)
- **Scope:** 10,602 public observations covering 17 Pakistani fashion brands across 7 platforms.
- **Reference URL:** [https://www.thesesjournal.com/index.php/1/article/view/3247](https://www.thesesjournal.com/index.php/1/article/view/3247)
- **Application:** Used as the structural benchmark for brand distribution, engagement ratios, and Roman Urdu sentiment vocabulary.

### B. Pakistan Largest E-Commerce Dataset
- **Repository:** Open Data Pakistan
- **Scope:** ~500,000 historical order transaction records including order status, payment methods (Cash on Delivery vs. Pre-paid), product categories, and buyer cities.
- **Reference URL:** [https://opendata.com.pk/dataset/pakistan-largest-ecommerce-dataset](https://opendata.com.pk/dataset/pakistan-largest-ecommerce-dataset)
- **Application:** Used to establish city-wise delivery expectations (Karachi, Lahore, Islamabad, Multan, Faisalabad, Peshawar, Quetta).

### C. Pakistani Fashion Catalogue
- **Repository:** Hugging Face Open Source Dataset (`Osama-Ansar/pakistani-fashion-catalogue`)
- **Scope:** Retail catalogue records from Pakistani fashion retailers with PKR retail prices and product categories.
- **Reference URL:** [https://huggingface.co/datasets/Osama-Ansar/pakistani-fashion-catalogue](https://huggingface.co/datasets/Osama-Ansar/pakistani-fashion-catalogue)
- **Application:** Used to set realistic Pakistani lawn suit price brackets (Rs. 2,990 to Rs. 14,990 PKR).

## 3. Data Integrity & Ethical Disclosure
- Simulated data and empirical reference data are strictly separated.
- Every simulated record is explicitly tagged with `data_source = 'simulated'`.
- No proprietary customer private messages or non-public personally identifiable information (PII) are stored.
